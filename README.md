# MediTrust Health Centre

**Your Health, Our Priority.**

MediTrust Health Centre is a professional healthcare website project based in Kakuma, Turkana County, Kenya. It is designed to provide visitors with healthcare information, service details, health education resources, contact information and convenient payment instructions.

## Project Overview

The website provides a responsive and user-friendly digital experience for patients and community members.

## Website Pages

1. **Home** – Introduction to MediTrust Health Centre.
2. **About Us** – Facility background, mission, vision and core values.
3. **Services** – Overview of healthcare services.
4. **Health Education** – Health awareness and educational resources.
5. **Our Team** – Healthcare team roles and responsibilities.
6. **Contact Us** – Enquiry form and contact information.
7. **Payments** – Payment options, instructions and transaction reference submission.

## Key Features

- Responsive desktop, tablet and mobile layouts.
- Light and dark theme switching.
- Mobile navigation menu.
- Contact enquiry form with EmailJS integration.
- Payment notification emails using EmailJS.
- M-Pesa payment instructions.
- Equity Bank PayBill instructions.
- Direct Equity Bank transfer instructions.
- Payment reference submission for manual verification.
- Health education information.
- Accessible navigation and form labels.

## Running Locally

1. Open the project folder in Visual Studio Code.
2. Open the Ubuntu terminal.
3. Navigate to the project directory.
4. Run:

```bash
python3 -m http.server 8003
```

5. Open your browser and visit:

`http://localhost:8003`
